Privacy policy

Last updated: 17 November 2026

Who uses this app

Shorts Uploader is a private tool used only by its owner to manage their own YouTube channels. It has no other users.

What data it accesses

With the owner's permission, the app uses the YouTube Data API to:

  • upload videos and thumbnails to the owner's channel (scope youtube.upload);
  • read the owner's channel ID and the details of the videos it uploaded, to check them (scope youtube.readonly).

How data is stored

The OAuth access tokens are stored only on the owner's computer. The app has no server and no database. It does not collect, sell or share any personal data, and it does not send data to anyone other than Google/YouTube.

Google API Services

Shorts Uploader uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions. Revoking it makes the stored tokens useless.
